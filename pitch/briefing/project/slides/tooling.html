10.2 COORDINATOR (USED). Drives agent threads through a CLI and waits for fresh reports.

10.3 NEXT. Findings dashboard, decisions inbox, stale-step alerts.

The tools guide (docs/tools.md) defines the events: prompt ready, step finished, verdict, task moved, decision to review, done.

Everything is plain Markdown with a strict naming grammar, so tools can be thin. The board panel was built as an editor plugin during the case study; the coordinator used an off-the-shelf agent-thread CLI. A team can start with zero tooling and add it as the loop becomes routine.
