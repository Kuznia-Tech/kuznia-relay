1.0  PROBLEM STATEMENT

Agents write code fast. Delivery still breaks.

1.1

Context dies in chat

Decisions, specs and status live in a scroll-back nobody can find on day four, or on another machine.

1.2

Self-review agrees with itself

The agent that wrote the code “reviews” it, fixes on the fly, and reports success without proof.

1.3

Stalls or runs wild

Left alone overnight, agents either wait on trivia or quietly change scope, requirements and shared machines.

Finding: the tools are adequate. The process around them is missing.

Most teams that try agentic coding hit the same three walls. The tools are fine; the process around them is missing. Kuznia Relay is that process.
