3.0  SEQUENCE OF OPERATIONS

Five steps per task, two of them checks

STEP 1

Analyze

Read-only agent answers questions with file:line proof

STEP 2 · CHECK

Spec check

Planner writes it; an agent checks it; owner approves

STEP 3

Build

Agent codes on its own branch, inside the spec, tests pass

STEP 4 · CHECK

Review

A fresh agent logs findings only; owner approves code

STEP 5

Done

Merge, full feature tests, tag, push; report the hash

One round: prompt → paste one line into a fresh agent → report → the planner updates the board. Eight short commands run the whole project.

Shaded, double-ruled steps are checks. They are the heart of the method. The round is deliberately boring: the owner types "prompt P1-T4", pastes one line into a new agent, then types "report P1-T4". Small tasks may skip Analyze, and the card says why.
