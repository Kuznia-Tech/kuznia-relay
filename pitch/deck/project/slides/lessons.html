GUARDRAILS

Every rule has an incident behind it

RuleBecause
Wait for a report newer than the step’s startRe-runs found the old report and looked done
Check the report file, not the agent’s statusAgents ended their turn “waiting for tests”
One writer per file, planners under a lockTwo writers produced duplicate decision rows
Kill by PID or port, never by patternA pattern kill hit another task’s test workers
Own scratch folder, own worktreeA shared test setup was gone when a later step needed it
Never skip commit hooksA commit dodged the checks CI runs

The spec and its extensions ship these as lessons tables, so a new team starts with them instead of rediscovering them.

This slide is usually what convinces engineering leads: it shows the method was hardened by real parallel agent runs on shared machines, not designed on a whiteboard.
