# Security policy

Kuznia Relay is documentation and templates, but it tells AI agents how to use git, push to remotes and run commands, so a rule that could lead an agent to leak secrets, push to the wrong place or damage a repository is a security issue.

## Reporting
Please report it privately through [GitHub's private vulnerability reporting](https://github.com/Kuznia-Tech/kuznia-relay/security/advisories/new), not in a public issue. We aim to reply within a week.

## Supported versions
Only the latest spec version gets fixes.
