# Pitch material

For presenting Kuznia Relay, not for running it. `SPEC.md` at the repo root is the source of truth.

| Path | What |
|---|---|
| `deck/` | Slide deck (`deck.json` plus slides) |
| `briefing/` | A shorter briefing deck |
| `spec.html` | The spec rendered as a web page |
| `spec-archive.html` | The spec rendered as a formal document |

Both HTML files embed a copy of `SPEC.md`; regenerate them when the spec changes.
