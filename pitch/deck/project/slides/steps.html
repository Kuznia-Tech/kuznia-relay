EVERY TASK

Five steps, two of them checks

1

Analyze

Read-only agent answers questions with file:line proof

2

Spec check

Planner writes it; an agent checks it against code and sources; owner approves

3

Build

Agent codes on its own branch, inside the spec, tests pass

4

Review

A fresh agent logs findings only; owner approves the code

5

Done

Merge, full feature tests, tag, push; report the hash

One round = prompt → paste one line into a fresh agent → report → the planner updates the board. Eight short commands run the whole project.

Orange steps are checks. They are the heart of the method. The round is deliberately boring: the owner types "prompt P1-T4", pastes one line into a new agent, then types "report P1-T4". Small tasks may skip Analyze, and the card says why.
