THE IDEA

The knowledge base is the state. Agents are interchangeable.

OWNER · 1 human

Approves and decides

Specs, code, scope, requirement calls. Nothing else.

PLANNER · LLM

Writes the docs

Plans, specs, prompts, board, decisions. May read the repo, never changes it.

AGENTS · fresh per step

Do one step

Read a prompt file, do the work, write one report with real git and test output.

One Markdown folder holds task cards, prompts, reports, decisions and the board. Any agent, any machine, any day picks up from the files.

Three roles. The human owns judgement. The planner owns the paperwork. Agents are disposable: a reviewer never wrote the code it reviews. Because state is in files, work moves between a laptop and a server overnight without losing anything.
